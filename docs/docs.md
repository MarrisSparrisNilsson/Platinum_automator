# Platinum automator Documentation

## Desmume Emulator window

### Sizes

Desmume has a few fixed window sizes that can be selected:

- 1x
- 1.5x
- 2x
- 2.5x
- 3x
- 4x $(1940 \times 856)$ -> Full screen width (24 inch monitor)
- 5x $(1940 \times 1020)$ -> Full screen width and height **stretched** (24 inch monitor)
